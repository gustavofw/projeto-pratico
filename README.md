## Funcionalidade planejada

Módulo de gerenciamento de tarefas, permitindo ao usuário criar, editar,
concluir e excluir tarefas, com filtro por status (pendente/concluída)
e ordenação por data de criação.

## Versionamento Semântico

O Versionamento Semântico (SemVer) é um padrão para numerar versões
de software no formato MAJOR.MINOR.PATCH.

- MAJOR: incrementado quando há mudanças incompatíveis com versões anteriores.
- MINOR: incrementado ao adicionar funcionalidades de forma retrocompatível.
- PATCH: incrementado em correções de bugs retrocompatíveis.

Exemplo: na versão 2.4.1, o "2" é MAJOR, o "4" é MINOR e o "1" é PATCH.
